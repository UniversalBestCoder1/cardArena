## Slide 4: 作品实现 - 关键技术 (Implementation)
### 4.1 泛型持久化框架 (The "DBHelper")
*   **痛点**：ArkTS 禁止反射，无 ORM 可用。
*   **创新**：自主封装 `DBHelper`，利用 Promise 锁解决异步初始化竞态问题；利用泛型接口统一 CRUD 操作。
*   **代码展示**：
    ```typescript
    // 异步初始化锁
    if (this.initPromise) await this.initPromise;
    // 泛型查询
    async query(tableName: string): Promise<ResultSet> { ... }
    ```

### 4.2 事务一致性 (Transaction Safety)
*   **场景**：赛事报名（扣钱 + 占位）。
*   **实现**：
    ```typescript
    // 伪代码
    beginTransaction();
    try {
       deductBalance(user);
       addEnrollment(user, tournament);
       commit();
    } catch {
       rollback();
    }
    ```

### 4.3 权限控制 (RBAC)
*   **实现**：UI 层根据 `User.role` 动态渲染入口。
*   **效果**：普通玩家看不到“裁判工作台”，保障系统安全。
